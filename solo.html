Crack the Code

Solo mode. You versus Gungebot. Run out of guesses and you get gunged.

Max guesses each

Cracking all four digits takes about 22 guesses on average. Correct guesses count too.

Gungebot's brain
  • The game picks a secret 4-digit code. You and Gungebot race to crack the same code.
  • Crack it one digit at a time, left to right. Guess right and that digit locks in, and you go again.
  • Guess wrong and it's Gungebot's turn. You can see how many digits it has locked, but not which numbers.
  • Every guess uses one from your allowance. Run out and you're out, and Gungebot plays on alone. First to lock all four wins.
