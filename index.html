Crack the Code

Four secret digits. Two players. First to crack the lock wins.

— or join a friend —

  • The game picks a secret 4-digit code (each digit 0–9). Both players chase the same code.
  • Crack it one digit at a time, left to right. Guess right and that digit locks in — and you go again.
  • Guess wrong and it's your opponent's turn.
  • You can see how many digits your rival has locked, but not which numbers. First to lock all four wins.
